## Как вести демо

1. Подбор — **тимлидом**, не «В комнату» у директора.  
2. Задачи назначать **фрилансеру**, не директору из селекта.  
3. Менеджер: inbox → Открыть → работать на карточке, не лезть в Обзор.  
4. Расторжение и колокольчик можно показывать — сценарии живые.
