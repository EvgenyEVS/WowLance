## Что прошло (139 сценариев ок, 0 пятисоток на золотом пути)

**Гость.** Лендинг, about/privacy/terms, логин, регистрация директора и фрилансера, баннер WOW Talent и автозаполнение (Иван Иванов / `ivan.ivanov@wowtalent.demo`). «Применить архитектуру» уводит на регистрацию директора. Гость с защищённых URL уходит на логин. 404 на мусорный путь. Logout GET = 405. Регистрация `role=admin` / `role=manager` отклонена. Open redirect через `next=` закрыт.

**Директор.** Дашборд с полосой «потратил / заработал / сэкономил». Мастер из трёх шагов, тестовая оплата, комната. Назначение тимлида и инвайт-ссылка. Правка вводных, HTML экранируется. Нет формы загрузки материалов (читательский empty-state). POST создания задачи не проходит. 403 на `/earnings/` и `/manager/inbox/`. С `/team/` и `/tasks/` редирект на Обзор. Каталог открывается.

**Тимлид.** Дашборд с формой «отчёт за период», страница отчёта 200 (инвертированные даты не 500). Каталог, поиск. Вкладка «Команда», добавление фрилансера, загрузка материала. Две разные Jitsi (команда и DT). Сообщения в командный и DT-чат. HTML в чате экранируется. Постановка задачи, утверждение отчёта, квалификация Hot.

**Фрилансер.** Шапка без каталога, кнопка «Я заработал всего N долларов». 403 на каталог, `/setup/`, чужую комнату, вкладку «Команда», DT-чат (GET и POST). Обзор: свои шесть цифр, вводные, «Готов к работе» сверху, без экономики и ленты. После ready кнопка пропадает. Свои задачи, отчёт со скрином, Quality Gate (закрыть без approve нельзя). Лид без контакта не создаётся; Hot сам не ставит. Видит файл, который загрузил тимлид. После approve обе кнопки показывают 10, в журнале есть строка; повторный approve вторую строку не пишет.

**Менеджер.** Inbox 200, в списке Hot-задачи. Каталог 403. Чужая комната 403. Карточка задачи из inbox — 403 (блокер выше).

**Прочее.** Статика на живом `runserver` ожидается 200 (у Django test client `/static/` не раздаётся — это не баг продукта). Кастомный `templates/403.html` есть; при `DJANGO_DEBUG=1` вместо него виден traceback — на VPS нужен `DJANGO_DEBUG=0`.
