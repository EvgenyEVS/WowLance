## Ветка biz/video — Видео обязательно для доступных фрилансеров
### Цель задачи
Реализовать требование MVP: фрилансер считается «доступным» и попадает в каталог только при наличии видеопрезентации в профиле.
### Что сделано
1. apps/profiles/forms.py — Валидация формы  
   Добавлен метод clean() в класс UserProfileForm:  
Если is_available = True, а video_url пустой — форма не проходит валидацию.  
   Ошибка привязана к полю video_url через self.add_error(), чтобы пользователь видел её рядом с нужным полем.
2. apps/profiles/views.py — Фильтрация в каталоге  
   В функции freelancer_catalog:  
Добавлен GET-параметр video_only (по умолчанию '1').  
   При video_only='1' из queryset исключаются профили с пустым video_url.  
   При video_only='0' показываются все профили (как раньше).  
   Флаг selected_video_only передаётся в шаблон для сохранения состояния чекбокса.
3. apps/profiles/templates/profiles/catalog.html — UI  
   В блок фильтров добавлен чекбокс «Только с видео» (включён по умолчанию).  
   На карточку фрилансера добавлены бейджи:  
🟢 «Есть видео» — если video_url заполнен.  
🔴 «Нет видео» — если video_url пуст.
4. apps/profiles/tests.py — Новые тесты  
   Добавлен класс FreelancerVideoRequirementTests с 3 тестами:  
test_form_validation_requires_video_if_available — форма не сохраняет профиль с is_available=True и пустым video_url.  
test_catalog_hides_profiles_without_video_by_default — каталог без параметров не показывает профили без видео.  
test_catalog_shows_all_when_video_only_is_0 — при ?video_only=0 показываются все профили.
5. apps/test_helpers.py — Обновление тестового хелпера  
Функция make_freelancer() теперь по умолчанию проставляет video_url='https://youtube.com/watch?v=test' для тестовых фрилансеров. Это предотвращает регрессию существующих тестов в apps.rooms, которые ожидают видимости фрилансеров в каталоге.

### Как проверить локально
Автоматические тесты
```
python manage.py test apps.profiles -v 2

```
Ручная проверка  
Валидация формы:  
Зайти под фрилансером → /profile/edit/.  
Поставить галочку «Доступен для заказов», очистить поле «Видеопрезентация», нажать «Сохранить».  
Ожидаемо: форма не сохраняется, под полем видео появляется ошибка.  
Каталог с фильтром:  
Зайти под директором → /freelancers/.  
Ожидаемо: чекбокс «Только с видео» включён, в списке только фрилансеры с бейджем «Есть видео».  
Снять галочку, нажать «Найти».  
Ожидаемо: в списке появляются все фрилансеры, у каждого — соответствующий бейдж.
### Архитектурные заметки (ADR-001)
Все изменения находятся в пределах модуля BIZ (apps.profiles).  
Нет импортов из apps.rooms или apps.pipeline — границы модулей соблюдены.  
Бизнес-логика (валидация) — в forms.py, фильтрация — в views.py.  
UI на русском, стили — inline (можно при необходимости вынести в static/css/style.css).
### Известные ограничения
Email-бэкенд оставлен в режиме console (как и было в master). Для реальной отправки писем требуется отдельная настройка SMTP, которая не входит в scope этой задачи.  
Бейджи на карточках используют inline-стили. При желании их можно вынести в CSS-классы в отдельном PR.
