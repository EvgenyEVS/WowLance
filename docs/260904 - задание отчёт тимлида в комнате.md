# Задание: форма отчёта за период под канбаном комнаты

| Поле | Значение |
|------|----------|
| **Дата** | 2026-09-04 |
| **Ветка** | `feature/room-teamlead-report-form` от актуального `master` |
| **Модуль** | ROOM: вкладка «Задачи» и Обзор; форма уже есть на дашборде тимлида |
| **Связано** | `apps/pipeline/teamlead_report.py`, `TeamleadPeriodReportForm`; [отображение по ролям](260831%20-%20отображение%20информации%20по%20ролям.md) §4.3 |

**Не трогать:** расчёт отчёта (`build_teamlead_period_report`), страницу результата `teamlead_report.html` (кроме ссылки «назад», если понадобится), Quality Gate задач, канбан-колонки, канал директор↔тимлид, каталог, начисления, колокольчик.

Это **тот же** отчёт «с / по / проект → Сформировать», не отчёт фрилансера по задаче.

---

## 1. Зачем

Отчёт за период сейчас только на дашборде `/`. Тимлид уже в комнате, смотрит доску — чтобы получить сводку, должен уйти на главную и заново выбрать проект. Нужна та же форма **в комнате, под канбаном**, с проектом этой комнаты уже выбранным. «Все проекты» и соседние свои комнаты в селекте остаются.

---

## 2. Кто видит

Только **тимлид этого проекта** (`project.teamlead_id == request.user.id`). Тот же смысл, что `user_can_create_task`.

| Роль | Форма в комнате |
|------|-----------------|
| Тимлид этой комнаты | да, под канбаном |
| Директор | нет (отчёт не его рабочее место; страница `/teamlead/report/` по-прежнему 403) |
| Фрилансер | нет |
| Тимлид чужой комнаты | нет доступа в комнату / формы нет |

Дашборд тимлида форму **оставить**. Там по умолчанию по-прежнему пустой проект = «Все проекты». Не подставлять туда текущую комнату: дашборд не про одну комнату.

---

## 3. Куда поставить

Полноценный канбан комнаты — вкладка **«Задачи»** (`apps/pipeline/templates/pipeline/room_tasks.html`). Форму — **сразу под** `.kanban-board`. Если задач нет (empty-state) — всё равно под этим блоком: доска пустая, отчёт за период всё равно нужен.

На **Обзоре** у тимлида тоже есть превью канбана (`room_overview.html`, ветка `{% else %}` с `.kanban-board`, не «Мои задачи» фрилансера). Туда — тот же partial **под** превью, чтобы не искать вкладку. Фрилансерский блок «Мои задачи» форму не получает.

Не ставить на Лиды, Материалы, Коммуникации, Команду.

Один partial, например `apps/pipeline/templates/pipeline/_teamlead_period_report_form.html`. Подключить:

- `teamlead_dashboard.html` (заменить текущую вёрстку формы, заголовок карточки дашборда можно оставить);
- `room_tasks.html`;
- `room_overview.html` (только тимлид этой комнаты).

`method="get"` `action="{% url 'pipeline:teamlead_report' %}"` — как сейчас. Новый URL и новая страница отчёта **не** нужны. После «Сформировать» открывается существующий HTML-отчёт.

---

## 4. Значение «Проект» по умолчанию

В `TeamleadPeriodReportForm` (`apps/pipeline/forms.py`):

- `empty_label` **«Все проекты»** не убирать и не переименовывать.
- Queryset по-прежнему `Project.objects.filter(teamlead=user)` — все свои комнаты, не только текущая.
- Добавить аргумент, например `initial_project=None`. Если передан проект и он есть в queryset — `self.fields['project'].initial = initial_project` (или `initial={'project': project}` до `super()`, как принято в форме).
- На Обзоре и Задачах: `TeamleadPeriodReportForm(user=request.user, initial_project=project)`.
- На дашборде: **без** `initial_project`, как сейчас.

В HTML выбран `<option>` текущей комнаты. Первая опция списка — «Все проекты». Можно сменить на другой свой проект или на все и нажать «Сформировать».

Не затирать выбор, если форма пришла связанной с GET (на странице отчёта GET уже выбирает проект из query). Комната отдаёт **несвязанную** форму.

Чужой `project_id` в GET отчёта — по-прежнему 403, это не менять.

---

## 5. Как сделать

1. Partial формы: заголовок «Отчёт за период», короткий текст что даты — задачи/отчёты/лиды, поля С / По / Проект, кнопка «Сформировать». Стили как на дашборде (`.feature-card` или `.upload-form` + `.form-row`).
2. `room_tasks`: в context `period_report_form` (имя не конфликтовать с `ReportSubmitForm` на карточке задачи — там другой `report_form`). На Обзоре то же имя.
3. `{% if period_report_form %}` — не по роли в шаблоне вслепую: в context класть форму только если пользователь — тимлид **этой** комнаты.
4. `teamlead_report.py` не переписывать. Не копировать агрегацию в `rooms/views.py`.

---

## 6. Что не делать

- Не считать отчёт внутри комнаты (вторая копия цифр).
- Не открывать форму директору «для прозрачности».
- Не убирать «Все проекты».
- Не менять дефолт дат (последние 7 дней).
- Не коммитить, если в промпте сказано не коммитить.

---

## 7. Приёмка

Расширить `apps/pipeline/tests_teamlead_report.py` (контур формы уже там):

1. Тимлид GET вкладки Задачи своей комнаты: 200, в HTML есть `pipeline:teamlead_report`, в селекте выбран **этот** `project.id`, есть опция «Все проекты», в queryset второй его проект тоже есть.
2. Тимлид GET Обзор той же комнаты: форма есть, selected = этот проект.
3. Тимлид GET дашборд `/`: у `report_form` **нет** обязательного selected этого проекта (initial проекта пустой / «Все проекты»).
4. Директор и фрилансер GET Обзор / Задачи (у директора Задачи редирект на Обзор): **нет** «Отчёт за период» / `name="project"` этой формы.
5. Submit GET `?project=<id этой комнаты>&date_from=&date_to=` с Задач — как раньше, 200 и блок отчёта; `test_building_the_report_writes_nothing` зелёный.
6. `python manage.py test apps.pipeline.tests_teamlead_report apps.pipeline.tests_kanban apps.rooms.tests_issue11_tabs_completion`

Ручной чеклист:

- Тимлид, вкладка Задачи комнаты A: под доской форма, в «Проект» стоит A. Сформировать → отчёт по A.
- Сменить на «Все проекты» → сводка по всем его комнатам.
- Сменить на комнату B → отчёт по B.
- Дашборд: селект без принудительной текущей комнаты, «Все проекты» по умолчанию.
- Директор на Обзоре той же комнаты: канбан есть, формы отчёта нет.
