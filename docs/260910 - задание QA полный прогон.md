## 2. Что не баг (stubs и продуктовые правила)

Не заводить тикет, если:

| Наблюдение | Почему так |
|------------|------------|
| Оплата без карты, «тестовая» | Stub запуска, не Stripe |
| «Заработал» у директора 0 ₽, подпись про сделки | Контура сделок нет |
| Начисления фрилансера в долларах, 10 за принятый отчёт, «не кошелёк» | Заглушка журнала |
| Jitsi на meet.jit.si, без пароля | ADR, не корпоративный Meet |
| Директор **без** вкладки «Задачи» | Операционка у тимлида |
| Фрилансер **без** каталога и вкладки «Команда» | Спека ролей |
| Фрилансер не ставит Hot | Только тимлид |
| Менеджер 403 на Обзор комнаты | Не член комнаты |
| Чеклист лида не двигает колонку Cold/Warm/Hot | Так задумано |
| Метрика «Team seats: N of M filled» по-английски | Зафиксированная подпись мест |
| При **первом** открытии страницы тоста по старым сообщениям нет | Курсор и last_poll = now, история не всплывает |
| Открыл вкладку «Коммуникации» — погасли и команда, и DT (если блок DT на странице) | GET отмечает оба канала, не только якорь |
| Нет 🔔, пока у роли нет ни одной комнаты с чатом | Колокольчик только если есть доступная комната |
| Бейдж `2` при двух сообщениях в **одном** командном чате | Баг: должно быть `1`. `2` — это два **разговора** (команда + DT или две комнаты) |

Писать баг, если: 500, 403 у того, кому страница нужна, пустой экран вместо формы, данные пропали, чужая роль видит чужой пульт.

## 5. P1 — роли на одном проекте (сид или тот же проект)

### Директор

- Дашборд: потратил / заработал / экономия; каталог не главный CTA.  
- Обзор: экономика, вводные, **Team seats: X of Y filled** (не подпись «Слоты» как единственный лейбл). Формы отчёта за период **нет**.  
- Коммуникации: командный чат **и** блок с тимлидом, две разные Jitsi.  
- Вкладка «Задачи» в шапке комнаты **скрыта**.

### Тимлид

- Каталог в шапке есть.  
- Команда: слоты, подобрать, участники.  
- Под канбаном на **Задачах** и под превью на **Обзоре**: «Отчёт за период», в селекте **эта** комната, есть «Все проекты». Сформировать → HTML-сводка, не пустая 403.  
- На дашборде `/` селект по умолчанию **не** прибит к одной комнате («Все проекты»).  
- Форма «Новая задача» есть, у директора и фрилансера на этой доске — нет.

### Фрилансер

- Обзор: свои цифры, вводные, мои задачи; нет состава/бюджета/ленты комнаты.  
- Задачи только свои.  
- Материалы: чтение; пустая папка — текст что загрузит тимлид, не «Загрузите как Dropbox».  
- Коммуникации: только команда, **нет** чата директор↔тимлид.  
- Кнопки заработка у логотипа и у названия проекта → история. Чужие роли этих кнопок не видят.

### Колокольчик (как сделано: `_header_chat_bell.html`, опрос `/chat-alerts/` каждые 7 с)

Место: шапка слева, после «Мастер запуска» / кнопки заработка, до меню. Иконка 🔔.

**Кто видит.** Директор, тимлид, фрилансер — и только если есть хотя бы одна их комната. Менеджер и гость: на дашборде нет `#header-chat-bell`. Фрилансер без комнат — колокольчика нет (не баг).

**Бейдж = число разговоров** `(комната + канал)`, не число сообщений.

| Состояние | Что на экране | Клик |
|-----------|---------------|------|
| 0 непрочитанных | 🔔 без цифры | Командный чат комнаты с последним видимым сообщением (`…/comms/#comms-team`) |
| 1 разговор | бейдж `1` | Сразу в этот чат: команда → `#comms-team`, DT → `#comms-dt-chat` |
| 2+ разговора | бейдж `2` (и т.д.), выпадающий список | Строка: **название проекта** + подпись канала («Команда» / «С тимлидом» / «С директором») |

**Тост** (всплывашка у колокольчика): автор, проект, канал, превью текста ~80 символов, клик = тот же URL, крестик закрывает. Появляется на **опросе** (вкладка браузера видима, ≤7 с), не при первой загрузке страницы. Несколько новых разговоров за один опрос — несколько тостов. Пока сидите на «Коммуникациях» этой комнаты — тоста и бейджа по её каналам быть не должно (poll с `viewing_comms=1`).

Прогон, два окна, **не обновлять F5** между шагами (иначе сбросится last_poll и тост по «новому» может не показаться как на первом заходе):

1. Директор на **дашборде** (не на Коммуникациях). Тимлид пишет в DT. У директора: тост + бейдж `1` → клик на `#comms-dt-chat`. После открытия Коммуникаций бейдж гаснет.
2. Не закрывая директора, фрилансер пишет в **командный** чат той же комнаты. У директора бейдж `2`, список из двух строк (Команда и С тимлидом). Не «2» от двух фраз в одном командном треде.
3. Фрилансер: в колокольчике нет «Секрет» из DT, нет `#comms-dt-chat`. Своё сообщение в команду бейдж не растит.
4. Тимлид: чужие team + DT → бейдж `2`, в списке «Команда» и «С директором».
5. Две комнаты, по одному непрочитанному в команде → бейдж `2`, в списке **два имени проектов**.
6. Текст `<script>alert(1)</script>` в чате: в тосте как текст, скрипт не выполняется.

### Расторжение

- «Удалить» у фрилансера **не** `confirm()` браузера, а форма с причиной (≥20 символов) и «Отправить фрилансеру уведомление о расторжении».  
- У Ивана модалка **по центру любой вкладки этой комнаты**; шапка сайта (Дашборд, Комнаты, Выйти) **доступна**. Есть «К списку комнат». Крестика «закрыл и работаю здесь» нет.  
- Список комнат: красная пометка, бейдж «Идёт расторжение — нужен ответ».  
- Пока кейс открыт: не стартует задачу / не создаёт лид (403 или отказ). Чат расторжения с тимлидом работает.  
- «Опротестовать» — **текст обязателен**; в чате кейса видно; работать нельзя; бейдж «Заблокировано, рассматривается увольнение».  
- «Покинуть»: слот пуст, задачи/лиды Ивана в БД на месте, комната в архиве, статистика читается.  
- Тимлид «Отозвать» до архива: модалка снялась, Иван снова берёт задачу.  
- «Другой сейлер» / удаление тимлида из таблицы — **не** ломать; при открытом кейсе этого фрилансера замену/удаление не давать.

### Карточка лида (чеклист)

- Слева ФИО/телефон, справа группы Need / Authority / Budget / Timeline / диалог / следующий шаг.  
- Узкое окно: контакт сверху, чеклист сразу под ним.  
- После F5 галочки те же (поле `discovery_checks` в БД — да, их можно будет агрегировать в статистике позже).  
- Тимлид видит и может править чеклист; директор — чтение; чужой фрилансер — 403.  
- Форма «Квалификация (тимлид)» на странице на месте.

### Менеджер после Hot

- Прямой URL Обзора комнаты — 403.  
- Ссылка на лид с карточки handoff, если есть: чтение, без смены квалификации.  
- Тимлид на **обычной** задаче комнаты: вкладки комнаты и «← К задачам» на месте.

## 6. P2 — регресс оболочки

| Проверка | Ожидание |
|----------|----------|
| Каталог фильтр «с видео» | В выдаче только с роликом |

| Командный чат: `<script>` в сообщении | Как текст, не выполняется |
| 403 страница | «Недостаточно прав», не traceback (на VPS `DJANGO_DEBUG=0`) |
| Фрилансер `/freelancers/` | 403 |
| Список проектов фрилансера | Заголовок «Комнаты», не «Проекты» как у директора |

## 7. Как оформлять находки

На каждую: роль, URL, шаги, ожидание, факт, скрин, приоритет (блокер демо / высокий / средний).

Не дублировать известное из §2. Не «некрасивый CSS», если сценарий проходит — в P3 в конце отчёта пачкой.

Итог прогона — короткий вердикт: **можно показывать / нельзя**, список блокеров.

Автотесты (не замена ручного прогона, дымовой):

```powershell
python manage.py test
```

Если красное — в отчёт: имя теста, не «сломалось всё».
