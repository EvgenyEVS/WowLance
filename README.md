# WowLance

WowLance — это веб-платформа для взаимодействия директоров и фрилансеров.

## Установка

1.  Клонируйте репозиторий.
2.  Создайте и активируйте виртуальное окружение.
3.  Установите зависимости: `pip install -r requirements.txt`.
4.  Скопируйте `.env.example` в `.env` и настройте переменные окружения (см. ниже).
5.  Выполните миграции: `python manage.py migrate`.
6.  Запустите сервер: `python manage.py runserver`.

## Настройка Email верификации через Gmail

Для отправки писем подтверждения регистрации (и других уведомлений) через Gmail выполните следующие шаги:

1.  **Включите двухфакторную аутентификацию (2FA)** в вашем аккаунте Google.
2.  **Создайте пароль приложения (App Password)**:
    *   Перейдите в настройки Google Аккаунта.
    *   Выберите "Безопасность".
    *   Найдите раздел "Пароли приложений" (или "Менеджер паролей").
    *   Выберите "Выбрать приложение" -> "Другое (Настроить название)" и укажите, например, "DjangoWowLance".
    *   Нажмите "Создать". Google сгенерирует 16-значный пароль.
3.  **Скопируйте** этот 16-значный пароль.
4.  **Настройте переменные окружения** в вашем файле `.env`:
    ```ini
    # ... другие переменные ...
    # Вставьте нужный адрес email
    EMAIL_HOST_USER=your_actual_gmail_address@gmail.com
    # Вставьте 16-значный "Пароль приложения" (App password), полученный в п.2
    EMAIL_HOST_PASSWORD=your_16_char_app_password_here
    EMAIL_HOST=smtp.gmail.com
    EMAIL_PORT=587
    EMAIL_USE_TLS=True
    # Убедитесь, что PUBLIC_HOST пустой для локальной разработки
    # или соответствует вашему публичному адресу для продакшена.
    # PUBLIC_HOST=your_public_ip_or_domain
    PUBLIC_HOST= # Оставьте пустым для локальной разработки
    # PUBLIC_SCHEME должен быть http для локальной разработки,
    # https для продакшена с TLS.
    # PUBLIC_SCHEME=https # для продакшена
    PUBLIC_SCHEME=http # для локальной разработки
    ```
5.  **Перезапустите** Django-сервер, чтобы он перечитал обновлённые переменные окружения.
6.  Теперь при регистрации пользователи будут получать письма с ссылкой для активации аккаунта на указанный email.
